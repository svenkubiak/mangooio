# mangoo I/O

**A lean, opinionated full-stack Java web framework. Everything you need, nothing you don't.**

mangoo I/O makes building modern Java web applications simple, productive, and enjoyable. From server-rendered websites to RESTful APIs, it provides a complete foundation without the complexity of assembling and configuring countless components.

Built on [Undertow](https://undertow.io/) and following the familiar MVC pattern, mangoo I/O embraces convention over configuration, sensible defaults, and clean Java code.

**Less configuration. Less boilerplate. More building.**

## Why mangoo I/O?

mangoo I/O brings together the essential building blocks of a modern web application in one cohesive framework.

- **Ready to go** — Start with a Maven archetype and a working application structure.
- **Convention over configuration** — Predictable project structure, straightforward routing, and minimal configuration.
- **Full-stack development** — Build dynamic websites with Freemarker or JSON APIs with Jackson.
- **Dependency injection** — Clean, modular applications powered by Google Guice.
- **Security built in** — Authentication, encrypted sessions, CSRF protection, CORS, and optional two-factor authentication.
- **Data and caching** — Integrated MongoDB persistence and high-performance Caffeine caching.
- **Background processing** — Scheduled jobs, asynchronous events, and email delivery.
- **Real-time communication** — Server-Sent Events and WebSocket support.
- **Production ready** — Health checks, metrics, tracing, graceful shutdown, and standalone JAR deployment.

Everything works together out of the box, while remaining extensible when your application needs something different.

## Getting Started

Getting started with mangoo I/O takes just a few steps.

Use the Maven archetype to create a new application, explore the generated project, and start building your first routes and controllers.

The framework provides development tooling, testing support, and a straightforward path from your first request to production deployment.
